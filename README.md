# SNAKE GAME WITH PYTHON 
This project was built using Python's built-in "Turtle" library.
It is one of the first games I've ever made!
## HOW TO PLAY
* Use **Arrow Keys**(Up, Down, Left, Right) to change the direction. The snake is always moving forward.
* Eat the food to grow and gain points.
* Avoid hitting yourself or the walls.
## HOW TO RUN
* Make sure you have **Python** installed in your computer.
* Download or clone this repository.
* Run the following command in your terminal:
```bash
python Snake-Game.py
